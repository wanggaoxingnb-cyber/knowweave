第 1 页 · 封面与必答三问

项目名：织识 KnowWeave —— 记得你学过什么、也知道你是谁（身份/爱好/熟悉领域）的 AI 学习助手

一句话定位：一个输入框通吃（文字/链接/Markdown/PDF/截图）→ LLM 意图路由 → 对话 + 舞台呈现 → 全 Markdown 记忆层（概念库 + 用户画像 + 待学习区 + 问答历史），用你熟悉的领域（英雄联盟、三角洲）举例，掌握度上图谱，越用越懂你。

必答三问（1 页内答完）

  1. 谁遇到这个问题？ 持续学习的职场人——尤其是想用 AI 时代知识给自己续命的在职产品经理。他们刷到好文章先收藏，收藏夹却永远吃灰；他们问 AI「这是什么」，AI 每次从零开始，不记得他上周学过什么；碎片时间一大把，整块学习时间每天只有 1-2 小时。问题不用很大，但每一个收藏夹里都躺着它。
  2. 现在怎么解决？ 用 ChatGPT/Claude 问一句答一句（不记得你、不检验、举例全是程序员视角）；用 Pocket/微信收藏囤积（只存不消化，Pocket 已于 2025 年关停，来源：产品官方公告及公开报道）；用 Notion 自己做知识库（维护成本高，坚持不下来）。
  3. 为什么值得重做一次？ 因为现在的组合拳缺两个环：检验（看过≠学会）和记忆（学过的要变成下一次学习的地基）。织识把「存 → 学 → 考 → 归档 → 编织 → 输出」做成一个任务闭环，记忆全部落成本地 Markdown 文件——透明、可带走、越用越懂你。这件事用 LLM 意图路由 + 本地记忆层就够便宜地做出来，值得重做。

第 2 页 · 痛点：收藏夹里的人生（P1–P6）

亲历故事（开篇）：2025 年，用了多年的 Pocket 宣布关停（2025-07，来源：产品官方公告及公开报道）。那一刻我打开自己的微信收藏夹——三百多篇文章，真正读完的不到二十篇。收藏的那一刻，我以为知识已经到手了；收藏本身，成了「我学过」的错觉。这就是我的第一用户画像：一个被收藏家谬误困住、又在碎片时间里拼命补课的职场人。

P1 收藏家谬误：收藏 = 读过，稍后读 = 永远不读。Pocket 死了，微信收藏夹活着但没人打开。（2025-07 Pocket 关停）

P2 通用 AI 不懂我：ChatGPT 每次从零开始：不知道我是产品经理、不记得我上周学过什么、举例全是程序员视角。

P3 知识是孤岛：文章各看各的，「回归测试」和「自回归」越学越混，没人帮我串联对账。

P4 看过 ≠ 学会：没有检验环节，自以为懂了，一被问就露馅。

P5 硬概念劝退：Transformer、Attention 纯文字越看越晕，缺一个「用我懂的方式演绎」的出口。

P6 没有路径感：想系统学一个领域时，不知道先学什么、后学什么，缺一个导师。（可汗学院的 Khanmigo 已验证 AI 导师需求，但通用家教产品不知道「我学到哪了」）

一句话：收藏是假的，学完才是真的。 问题真实、普遍、且所有人都在用「不解决问题的方案」对付它。

第 3 页 · 解法：一个输入框，把「收藏」变成「学完」

织识是什么：一个本地的 AI 学习工作台。喂任意资料，它生成图文讲解与播客音频，把新知识和旧知识织成一张越织越大的网，并始终用你熟悉的东西举例。

核心流程（任务闭环）

  1. 输入：一个框通吃——打字提问、粘贴链接、拖入 Markdown/PDF、丢截图（macOS Vision OCR 取字）。
  2. 意图路由（LLM 路由，用户永远不选按钮）：Agent 判断这次是「讲解 / 学习 / 收藏 / 编织 / 检验 / 演绎 / 导师 / 创作 / 闲聊」九类意图之一，自动分配处理管线。
  3. 呈现（对话+舞台）：主界面=对话区（短回复+可回看引用卡）＋右侧舞台（概念卡/学习页/图解/路径/播客，标签切换）；知识图谱、待学习区、用户画像收成顶栏三个入口：图谱全屏铺开（vis-network，点节点跳详情），待学习右侧抽屉，画像弹层可编辑写回。
  4. 记忆层（全 Markdown，透明可翻）：concepts/ 概念卡 · profiles/ 用户画像 · inbox/ 待学习区 · data/history/ 问答留痕。自生长四条规则：问到新概念自动建档、问到旧概念升级掌握度并联新边、每次问答留痕、流露的身份信号记入画像。
  5. 越用越懂你（信号沉淀）：每次回答顺带提取 signals（身份/熟悉领域/卡点/显式「记住这个」），只记你说出口的、可看可改可删；「它眼中的你」面板实时可见。

弹药库飞轮（核心机制）：掌握度 ≥「能讲给别人」的概念自动进入举例弹药库——你学懂的领域，会变成给下一个陌生领域举例的材料。英雄联盟 → 测试概念 → AI 概念，层层叠加，越学越快。

设计原则一句话：不上来给选择，在场景里给推荐，推荐必带理由，用户可一句话否决。

第 4 页 · 产品演示：用织识的一天（S1–S7 场景线）

以下按真实场景线走一遍，每个场景 = 一句用户视角 + 一句产品动作：

  • S1 通勤种草：地铁上刷到好文章没空读，丢链接说「先存着」→ 织识抓正文、抽一句话种草点，秒存待学习区，不打断通勤（😌 没丢，安心）。
  • S2 碎片消化：午休只有 5 分钟，点「听个大概」→ 织识只生成 60 秒播客摘要，耳朵先学（🎧 先听个大概）。
  • S3 晚上深学：整块时间到了，点「开始学」→ 完整学习页：导读 + 概念卡 + 检验题 + 播客，掌握度落库（😃 真学会了）。
  • S4 主动攻坚：说「我想系统学 LLM 原理」→ 切导师模式，出学习路径：先学哪 3 个、为什么、每步串联你已会的（🧭 有方向了）。
  • S5 卡住求助：Transformer 看三遍没懂，说「太难了，画给我看」→ 生成自包含 HTML 图解/交互动画，二次查看秒开缓存（🤯→💡）。
  • S6 编织对账：隐约觉得两个概念有关系，问「RAG 跟幻觉什么关系」→ 讲清关系 + 建双链 + 图谱长边高亮（🤩 连起来了）。
  • S7 周末回顾：看看这周学得怎样 → 图谱按掌握度着色，生疏的节点一键重新考我（😎 有掌控感）。

完整任务闭环：输入 → Agent 理解/调用工具（抓取/OCR/TTS/HTML 生成）→ 输出概念卡/播客/图解/路径 → 记忆写入 → 下次自动带上旧知识与画像。这条链路在本地可运行的产品中真实跑通，非概念方案。

第 6 页 · 技术架构与数据合规

架构（如实标注）

  • 后端：Python FastAPI 单页应用（app/main.py 路由 + brain.py 大模型调用 + memory.py Markdown 记忆层）。
  • AI 大脑：OpenAI 兼容 LLM 网关（默认 DeepSeek 系列模型，.env 配置 base_url/key/model），负责意图路由、JSON 结构化输出、讲解/出题/演绎/路径生成；无 key 时自动进入 mock 兜底模式（内置演示答案），保证演示不翻车。
  • 工具调用（真实实现）：网页正文抓取、PDF 文本提取（pymupdf）、截图 OCR（macOS Vision，免装依赖）、中文播客（edge-tts）、演绎图解（LLM 生成自包含 HTML + data/viz/ 缓存秒开）。
  • 记忆层：纯 Markdown 文件夹（concepts/profiles/inbox/history），无数据库、无向量库——这是刻意选择，保证透明、可备份、可人工审阅。
  • 图谱：vis-network（本地内置 vendor 文件，离线可演示），从概念双链 [[...]] 生成。
  • 前端：单页应用（对话+舞台布局 + 图谱全屏覆盖层），零框架依赖。

数据合规（命中官方关键词）：所有记忆数据全本地存储、零上传。LLM 调用只在提问时发送本次输入与检索到的相关记忆，记忆库本体不离开用户电脑；.env 中的 key 已 gitignore，不入库、不提交。无账号体系、无云端同步（【Roadmap】多用户/云同步）。

开源与 API 来源如实声明：FastAPI / openai SDK / pymupdf / edge-tts / vis-network 均为开源组件；LLM、TTS 为第三方 API 服务；截图 OCR 使用 macOS Vision 本地能力。演示素材仅用公开资料，不含公司内部数据。

第 7 页 · 商业模式（轻写，不吹）

目标用户：持续学习的职场人——产品经理、运营、文科生、备考与自学者（官方「不只属于程序员」的画像正好重叠）。

收费模式：

  • 个人版（先做）：订阅制，面向「每天 30 分钟碎片 + 晚间 1-2 小时整块」的学习人群，价值锚点是「收藏不再吃灰 + 学过的知识不丢」。定价对标知识管理/稍后读工具的常见订阅区间，随版本验证调整。
  • 团队版（后做，【Roadmap】）：学习数据本身是个人资产，团队版按「学习工作台 + 团队知识沉淀」扩展，暂不展开。

为什么敢收费：不是「又一个问答框」，而是用户自己的记忆资产在本地持续生长——迁移成本高、留存天然强；弹药库飞轮让越用越值的感受可感知。

克制声明：本方案为黑客松参赛作品，商业模式为方向性构想，未做市场验证，无虚构市场规模数字。
