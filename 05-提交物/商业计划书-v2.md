# 织识 KnowWeave：把我的收藏夹，变成一个真的记得我的学习助手

> MINMAX 粤港澳大湾区创客 AI Agent 黑客松挑战赛 · 参赛人：王宁 · 2026-11-08

## 01 起心动念：我有六个收藏夹，全是坟场

微信收藏里躺着三百多篇"好文章"，B站收藏夹吃灰的教程排到三年前，YouTube、公众号、小红书、抖音——每换一个 App，我就多一座收藏坟场。点收藏的那一刻，我总以为知识已经到手了。

我是一名在职 AI 产品经理。这个身份逼着我保持学习：既要懂业务，又得追得上前沿技术。AI 时代，学习不是加分项，是生存技能。可我的真实状态是：碎片时间一大把，整块时间每天只有一两个小时；遇到好内容先收藏，收藏完就再也没打开过。

今年看到这个黑客松，题目正好像一记耳光：「过去问 AI 能做什么，现在问——你能用 AI 做出什么？」我不想再收藏这个问题了，我想动手回答它。

**谁遇到这个问题？** 每一个试图持续学习的职场人。问题不用很大，但它真实地躺在我们每个人的收藏夹里。

**现在怎么解决？** 问豆包、问百度，答案很散，问完就断片；用 Obsidian、Notion 自己建知识库，维护成本高到坚持不下来；继续往收藏夹里扔，然后假装自己会读。Pocket 做到 2025 年关停了——它证明了稍后读是真需求，也证明了"只存不消化"没有出路。

**为什么值得重做一次？** 因为现有方案缺了两个环：**消化**（存了要学）和**记忆**（学过的要成为下一次学习的地基）。而这两件事，今天用 LLM 已经能便宜地做出来。

## 02 痛点拆解：三个坎，我全都踩过

**坎一：收藏 ≠ 学会。** 收藏制造"我学过"的错觉。没有消化机制，收藏夹只会变大，不会变厚。

**坎二：通用 AI 不懂我。** 我问 ChatGPT「灰度测试是啥」，它给我一段教科书定义。它不知道我是产品经理，不知道我上周刚学完回归测试，更不可能拿英雄联盟新版本先上测试服给我举例——而那个例子能让我三秒钟就懂。

**坎三：知识是孤岛，看过就断片。** 文章各看各的，RAG 和幻觉明明有关系，没人帮我连起来。脑子里没有图谱，学完一周，什么也剩不下。

一句话：**收藏是假的，学完才是真的。**

## 03 产品是什么：织识，一个会生长的学习工作台

**一句话：织识是一个"记得你学过什么、也知道你是谁"的 AI 学习助手——喂给它任何资料，它帮你消化成自己的东西，并且越用越懂你。**

用起来是什么样？我的一天：

- **通勤**：刷到好文章没空读，丢个链接说"先存着"。它抓正文、留一句种草点，进待学习区，十秒搞定，不打断我。
- **午休**：只有五分钟，点"听个大概"，它生成一段 60 秒的播客，耳朵先学。
- **晚上**：整块时间，点"开始学"，导读、概念卡、检验题、播客，一页给齐。学完归档，掌握度落库。
- **卡住了**：说"Attention 太难了，画给我看"，它生成一张能点的交互图解；第二次再问，秒开。
- **串不起来**：问"RAG 跟幻觉什么关系"，它讲清楚，还在我的知识图谱里织上一条边。
- **周末**：打开图谱，灰的是刚认识，绿的是能讲给别人，颜色就是掌握度。点开节点能看当时学的内容，还能一键"再考我"。
- **随时**：打开"它眼中的你"，看它记住了我什么——身份、行业、熟悉领域、最近聊出来的信号，全部透明，可改可删。

这条链路是**闭环**：输入 → 理解 → 产出 → 记忆 → 下次提问自动带上旧知识和我的画像。学的东西真的在累积。

## 04 四个关键决策：它为什么长这样

做产品的过程，就是做取舍的过程。这四个决策定义了织识。

**决策一：记忆用本地 Markdown 文件，不用数据库，也不上向量库。**
ChatGPT 的记忆是黑盒——你不知道它记了什么，也带不走。织识的记忆就是一堆 Markdown 文件，躺在本地文件夹里，逐字能看、能改、能删、能拷走，零上传。个人知识量级下，关键词检索 + LLM 路由足够快、足够准。透明，比"先进"更重要；数据主权，是这个产品的地基。

**决策二：一个输入框通吃，意图让 AI 路由，不给用户按钮菜单。**
学习场景里，用户常常说不清自己想要什么——"讲解""学习""收藏""考我"不该是用户的负担。我把意图判断交给 LLM，九类意图自动路由；拿不准就降级到最安全的"讲解"。用户只管用自然语言说话。

**决策三：记忆必须有掌握度和检验，否则只是又一个收藏夹。**
每个概念有四档掌握度：刚认识 → 理解了 → 能讲给别人 → 能用。答错当场讲评，答对掌握度涨一档。看过不等于学会，被考过才算。

**决策四：用用户熟悉的领域举例。**
AI"不懂我"的本质是上下文缺失。织识每次回答都会读用户画像和已有概念库：给我讲灰度测试，用的是英雄联盟新英雄先上测试服；给下一个人讲，可能就是他熟悉的领域。学懂的领域还会进入"弹药库"，变成给陌生领域举例的材料——越学越快。

## 05 两天怎么做出来的：踩坑、重构与 AI 原生协作

我只有两天。11 月 7 日傍晚开工，两小时后，带意图路由的产品骨架就跑通了。剩下的时间，全花在让它"真的能用"上。

**踩坑：被 AI 的"思考"坑了一个晚上。** 演绎功能起初一直返回空白——排查发现，推理模型把"思考"过程算进了输出额度，正文被烧光了。解法：所有生成类调用显式关闭思考、超时放宽、JSON 截断兜底解析，再把生成过的图解缓存下来，二次秒开。这个坑让我记住一件事：用大模型做产品，能力边界和工程兜底，比模型多强更重要。

**重构：被真实试用打回原形。** 第一版是教科书式的三栏：左对话、中产出、右图谱。我自己真用起来才发现：面板是死的拖不动，点一下待学习区，产出区内容就没了，图谱挤在角落里根本看不清。我当时就一句话：这交互太恶心了。当夜推翻重构：对话 + 舞台两栏，重产出上舞台，图谱收成入口、点开全屏铺开，画像做成弹层可编辑。现在这版，是我一条条骂出来的。

**协作：我自己就是 AI 原生的工作方式。** 我不懂代码，全部代码由 Codex 这类 AI 编程工具完成，我负责发现问题、做判断、验收结果。白天在这台电脑上做产品，晚上把写作任务打包成交接文档，扔给另一台电脑上的 Agent 挂机跑，早上回来合并验收。织识本身就是"一个人 + AI 协作能做出什么"的活例子。

## 06 取舍与下一步

**做了的取舍，我都认。** 只有两天，我把火力集中在"记忆闭环"这一个差异点上：生图、生视频形态没接（想法聊过，判断是来不及，放进迭代规划）；复习提醒、划词插件、多端同步，也都进了规划而不是硬塞。做产品不是堆功能，是敢于不做。

**下一步**：掌握度随时间衰减与"快忘了"复习提醒、浏览器划词插件、生图/生视频产出形态、云端多端同步。方向是把它做成一个真正长期的个人学习资产库。

**为什么是我做这件事**：我不是程序员，是一个用 Codex 把产品做出来的产品经理。织识对我是双重的：它既是我给自己做的学习工具，也是我练习"发现问题、判断取舍、推动落地"的作品。官方那句话我想用在这里——过去问 AI 能做什么，现在问：你能用 AI 做出什么？这是我的答案。

## 07 附：技术与合规速览

- **形态**：本地运行的 Web 应用（Python FastAPI + 单页前端），评委按说明 5 分钟可跑起来；未配置 key 时自动进入演示兜底模式。
- **AI 大脑**：OpenAI 兼容 LLM 网关，负责意图路由与全部生成；概念卡、学习页、图解、出题判题、路径规划均为结构化输出。
- **工具调用**：网页正文抓取、PDF 文本提取、macOS 截图 OCR、中文播客合成、自包含 HTML 图解生成（带缓存）。
- **记忆层**：纯 Markdown 文件夹（概念库/用户画像/待学习区/问答留痕），知识图谱由概念双链生成，本地组件渲染，可离线演示。
- **多模态**：文字/链接/Markdown/PDF/截图输入；图文卡/播客/交互图解输出。
- **数据合规**：记忆全本地、零上传；调用 LLM 时只发送本次输入与检索到的相关记忆；无账号体系；密钥不入库。
- **开源与 API**：FastAPI、openai SDK、pymupdf、edge-tts、vis-network 均为开源组件；LLM 与 TTS 为第三方 API；演示素材仅使用公开资料。
