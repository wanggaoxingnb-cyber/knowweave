# 织识 KnowWeave — 5 分钟跑起来（评委体验说明）

> 给完全没见过这个项目的人。跟着做，5 分钟内能打开产品并试完核心功能。
> 版本：v0.1 初稿 · 2026-11-07 · 所有命令已对照 `02-产品Demo/` 代码逐一核对。

## 这是什么

织识是一个本地的 AI 学习助手：**一个输入框通吃**（提问 / 链接 / Markdown / PDF / 截图），AI 判断你想干嘛（讲解 / 学习 / 收藏 / 考我 / 演绎…），把内容讲成图文概念卡和播客，并记进**本地 Markdown 记忆库**——下次提问自动带上你学过什么、知道你是谁（产品经理、喜欢英雄联盟）。

## 环境要求

- **macOS**（截图 OCR 用系统自带 Vision，仅 macOS 可用；Windows 也能跑其余功能）
- **Python 3.9+**（终端输入 `python3 --version` 确认）
- 网络：首次安装依赖需要联网；生成播客/图解走云端 API；**没配 key 也能跑**（自动进 mock 兜底模式，详见「常见问题」）

## 最快上手（推荐）

- **Mac**：双击 `双击启动-Mac.command`（如被系统拦：右键 → 打开 → 打开）。首次等 1-3 分钟装依赖，之后浏览器自动打开产品
- **Windows**：双击 `双击启动-Windows.bat`

## 5 分钟跑起来（手动方式）

打开终端（Terminal），逐条执行：

```bash
# 1. 进入 Demo 目录（假设项目文件夹叫「织识」，在你下载的位置）
cd 织识-Demo

# 2. 创建独立运行环境（约 30 秒）
python3 -m venv .venv

# 3. 激活
source .venv/bin/activate

# 4. 安装依赖（约 1-3 分钟，一次即可）
pip install -r requirements.txt

# 5. （可选，强烈建议）配置 AI 接口，体验完整功能
cp .env.example .env
#   用文本编辑器打开 .env，填入三行：
#   LLM_BASE_URL=你的接口地址
#   LLM_API_KEY=你的密钥
#   LLM_MODEL=模型名（示例：deepseek-v4-flash-0731）

# 6. 启动（出现 "Uvicorn running on http://127.0.0.1:8000" 即成功）
python -m app.main

# 7. 浏览器打开
#    http://localhost:8000
```

可选：想回到「用了一周」的演示状态（图谱已有十几个节点、画像有内容），另开一个终端执行：

```bash
cd 织识-Demo && bash scripts/reset-demo.sh
```

## 常见问题

- **没配 key 能跑吗？** 能。自动进入 mock 兜底模式，讲解类（回归测试/灰度测试）有内置演示答案；但学习页生成、演绎、播客、考我判分等 LLM 生成功能会降级或不可用，**建议配 key 完整体验**。
- **图谱/播客没出来？** 播客走 edge-tts 需要联网；演绎首次生成较慢，第二次起走缓存秒开。
- **截图识别不灵？** OCR 仅 macOS 可用；Windows 上请改用粘贴文字或上传 PDF。
- **演示数据被我玩乱了？** 执行上面的 `bash scripts/reset-demo.sh` 即可一键还原种子状态（演绎缓存保留，秒开效果还在）。
