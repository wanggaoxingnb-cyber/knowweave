## 0. 一句话定位
**记得你学过什么、也知道你是谁（身份/爱好/熟悉领域）的 AI 学习助手。**

## 1. 核心链路（必须跑通的一条）
用户输入（链接/文件/提问）→ Agent 解析 + 检索记忆（知识 + 用户画像）→ 生成输出（图文卡/音频/串联回答，用你熟悉的东西举例）→ 更新记忆 → 下次提问自动带上旧知识和你的画像

## 3. 记忆层 schema（产品地基）
记忆 = 知识概念库 + 用户画像，两份都是 Markdown，AI 自动读写。

### 3.1 概念文件 `concepts/<概念名>.md`
```
---
名称: 自回归模型
掌握度: 理解了          ← initial → 理解了 → 能讲给别人 → 能用
来源: 知乎文章《xxx》
相关概念: [[Transformer]] [[回归测试]]
首次学习时间: 2026-11-07
更新时间: 2026-11-07
---
大白话解释: ...
我当时的疑问: ...
一句话记忆钩子: ...
```

### 3.2 用户画像 `profiles/user.md`
```
---
身份: 产品经理
行业: 直销（完美）
熟悉领域/爱好: 英雄联盟、三角洲（射击游戏）、测试相关知识待补（冒烟/回归/灰度/测试用例/验收测试）
举例偏好: 游戏 / 直销 / 门店场景
---
```

**自生长四条规则**
1. 问到新概念 → 自动新建概念文件
2. 问到旧概念 → 更新掌握度 + 本次串到的概念加入关联
3. 每次问答留痕 → 提问记录可回看成长轨迹
4. 每次问答中流露的身份/爱好/熟悉度信号 → 记入用户画像

## 4. 架构（人话版）
- 网页：单页（输入口 / 结果区 / 图谱区）
- AI 大脑：DeepSeek（解析 / 串联 / 生成 / 选形态 / 选例子）
- 记忆：concepts/ + profiles/ Markdown 文件夹
- 输出：图文卡 + 音频（edge-tts）+ 图谱（前端可视化）
- 技术栈：Python FastAPI + 单页前端 + DeepSeek API + edge-tts（代码由 Codex 写，王宁验收）
