五、两个新模块的细节设计

5.1 待学习缓存区（解 P1 收藏家谬误）

  • 关键洞察：稍后读工具全死在"只存不消化"。织识的缓存区自带消化机制——这是和 Pocket/微信收藏的本质差异。
  • 存：丢链接说"先存着"→ 抓正文、抽一句话种草点（为什么值得读）、存 inbox/。秒级完成，不打断通勤。
  • 消化两条路：每条目两个按钮——「开始学」（走完整学习页，S3）｜「听个大概」（只出 60 秒播客，S2）。
  • 防吃灰：周末回顾（S7）时提示"你有 3 篇存了超过 5 天没学"；学过的条目自动归档。
  • 存储：memory/inbox/<标题>.md（frontmatter：标题/链接/种草点/存入时间/状态），全透明。

5.2 导师模式 vs 举例模式（解 P6 路径感）

举例模式（默认，被动）
学陌生概念时，用你高熟悉度领域（英雄联盟）举例。适合"遇到啥学啥"。
导师模式（主动，你说"我要系统学XX"触发）
它读你的图谱和画像，出学习路径：先学哪 3 个概念、为什么、每步串联你已经会的什么。路径挂在中栏，学一个勾一个。
最终方案：阶段感知路由（模式不靠用户选）
模式是 Agent 根据你的学习阶段自动路由的状态，不是开关：
· 概念全是 initial（新领域）→ 默认概念讲解模式
· 平均掌握度到「理解了」（半桶水）→ 对话里无痛推荐："你最近问了 3 个 RAG 相关的，要不要考考你？"一键接受/拒绝，拒绝就继续讲
· 主动说"我要系统学 XX" → 进导师模式，出现「🧭 攻坚：XX」标签，可点退出
原则：不上来给选择，在场景里给推荐，推荐必带理由，用户可一句话否决。

5.3 输出倒逼输出（费曼模块，解"学完没产出"）

  • 理念：费曼学习法——能讲给别人/写出来，才算真学会。输出是检验，也是资产。
  • 说什么："把最近学的写成一篇文章" / "给我三个大纲" / "围绕 RAG 写篇公众号原稿"
  • 它做什么：去知识图谱检索相关概念 + 翻问答留痕（你当时踩的坑、悟到的最佳实践）→ 生成第一人称视角的自媒体原稿（"我怎么把 RAG 学明白的"），中栏渲染，可复制/下载 Markdown
  • 接 Agent：可生成一段「给内容创作 Agent 的交接提示词」——包含大纲、素材清单（你的概念卡+你的坑+你的金句），粘给任何创作 Agent 接着干
  • 专业人设价值：持续输出"新技术×我的业务"的串联文章，就是这一行的专业性证明

六、越用越懂你（信号沉淀机制，已确认规则）

  • 提取什么：身份/熟悉领域+熟悉度/学习目标/认知风格/卡点/显式"记住这个"
  • 何时提取：随每次回答顺带输出 signals 字段，零额外调用，实时
  • 边界：只记用户明确说出口的，不推测不贴标签；弱信号进"待确认区"先问再用；每轮最多沉淀 1-2 条；语音输入的啰嗦错字自动降噪
  • 反哺：高熟悉度领域优先举例；复习时故意换领域出题验证真懂；用了新偏好时标注"（用了你说过的 ADC）"
  • 弹药库飞轮（核心机制）：掌握度≥「能讲给别人」的概念自动加入举例弹药库——你学懂的领域，会变成给下一个陌生领域举例的材料。英雄联盟 → 测试概念 → AI 概念，层层叠加，越学越快。
  • 透明：「它眼中的你」面板，每条画像可看可改可删
