## 三、产品需求（已确认；更细版本见文件夹 `01-需求与文档/织识-开工卡-2026-11-07.md`）
P0（Demo 必须有）：
1. 输入：粘贴文本 / 上传 Markdown·PDF·截图 / 直接提问
2. 记忆：Markdown 概念文件夹，AI 自动新建/更新
3. 串联回答：回答时检索相关旧概念，带「你学过XX」上下文（关键演示：回归测试 vs 自回归 防混）
4. 输出形态1：图文概念卡
5. 输出形态2：播客音频（edge-tts 中文音色）
6. 图谱：从概念双链生成可视化，demo 中高亮相关节点
7. 身份感知举例：读用户画像（身份=产品经理、熟悉领域=英雄联盟），用熟悉的东西举例（如用英雄联盟新英雄灰度上线讲灰度测试）

P2（停车场）：视频生成、语音克隆、多用户、移动端、社媒自动抓取、Neo4j/向量库升级

## 四、记忆层 schema（产品地基，改动需与我确认）
记忆 = 概念库 + 用户画像，两份都是 Markdown。
- 概念文件 `concepts/<概念名>.md`：frontmatter = 名称/掌握度(initial→理解了→能讲给别人→能用)/来源/相关概念(双链[[]])/首次学习时间/更新时间；正文 = 大白话解释 / 我当时的疑问 / 一句话记忆钩子
- 用户画像 `profiles/user.md`：身份/行业/熟悉领域(英雄联盟、三角洲射击游戏)/举例偏好(游戏、直销、门店)
自生长四条规则：
1. 问到新概念 → 自动新建概念文件
2. 问到旧概念 → 更新掌握度 + 本次串到的概念加入关联
3. 每次问答留痕 → 提问记录可回看成长轨迹
4. 问答中流露的身份/爱好/熟悉度信号 → 记入用户画像

## 五、技术方案（已定，不要擅自换成重型方案）
- Web 单页（输入口 / 结果区 / 图谱区），Python FastAPI 后端，代码全部你写，我验收
- AI 大脑：DeepSeek API（解析 / 串联 / 生成 / 选形态 / 选例子）
- 记忆：concepts/ + profiles/ 纯 Markdown（不上数据库、向量库、Neo4j）
- 音频：edge-tts 免费中文音色
- 图谱：前端可视化（如 vis-network / Mermaid），从概念文件双链生成
- 运行：本地可跑优先；公网部署是加分项，时间不够就用「本地运行说明 + 录屏视频」兜底
