一、用户旅程图（一次完整学习闭环）

① 遇到资料② 入库学习③ 理解串联④ 检验掌握⑤ 编织成网⑥ 回顾复习
用户行为 通勤刷到一篇 RAG 公众号文章，觉得有用 把链接直接贴进输入框（或拖 PDF/截图） 看学习页：导读分段读，概念卡逐个过 答学习页底部的检验题；或主动说"考考我" 问"RAG 跟我学过的幻觉是什么关系" 周末打开图谱，看哪片密、哪片荒
触点 微信/浏览器 → 织识输入框 左栏对话区（统一入口） 中栏产出区 + 播客音频 概念卡上的「考考我」+ 对话区答题 对话区 + 右栏图谱 右栏图谱（点节点看详情）
情绪曲线 😐 又一篇，先码住 🙂 丢进去就行，不用选按钮 😃 它用英雄联盟讲，我真懂了 😅 答错一题 → 😌 换例子重讲后懂了 🤩 图谱上两个点连起来了！ 😎 原来我这周学了这么多
没有织识时
的痛点		 收藏夹吃灰，"码了=学了" 要自己读全文、做笔记，坚持不下来 ChatGPT 举例不对背景，也不记得我学过啥 看过≠学会，没有被检验的机会 概念之间关系全靠自己脑补，越学越混 学了哪些、忘了哪些，完全没数
织识的动作 统一输入框，贴链接即抓取正文 LLM 生成学习页：总结+导读+概念卡+检验题+播客 读用户画像，用熟悉领域举例；自动带"你学过XX"防混提示 出题→判题→掌握度真实升降；答错换个例子重讲 识别概念、建立双链、图谱实时长边 图谱按掌握度着色；问答留痕可回看成长轨迹
验收信号
（demo 可演示）		 贴公众号链接，10 秒内出学习页 学习页五件套齐全（总结/导读/卡/题/播客） 问"自回归"→ 提示"别和回归测试混" 答错后图谱上该节点掌握度降级变色 图谱当场新增一条边并高亮 图谱节点颜色反映掌握度梯度

二、交互逻辑图（一个框进，三栏出）

统一输入框（左栏对话区）
打字提问贴链接拖 md/txt/pdf拖截图拖文件夹
没有"提问按钮/入库按钮"之分，用户永远不用选
▼
LLM 意图路由（一次调用，模型自己判断）
规则辅助：带文件/链接 → 必走「学习」；纯文字 → 模型判断意图
▼
① 讲解
"回归测试是啥"
→ 图文卡 + 你学过XX串联 + 防混提示 + 播客
写记忆：新概念建档 / 旧概念掌握度+1
② 学习
贴文章/链接/文件
→ 学习页：总结+导读+概念卡+检验题+播客
写记忆：1-3 个概念建档，来源=该资料
③ 编织
"RAG 和幻觉什么关系"
→ 讲清关系 + 建立双链 + 图谱长边高亮
写记忆：两个概念互加 [[双链]]
④ 检验
"考考我"
→ 出 3 题（定义→辨析→应用）→ 判题 → 答错换例子重讲
写记忆：掌握度升/降一级
⑤ 演绎
"Transformer 太难了，画给我看"
→ 生成自包含 HTML 图解/交互动画，中栏直接渲染
写记忆：概念卡追加"演绎"区块
⑥ 闲聊
"你好"、"今天学什么好"
→ 正常对话（带画像与记忆上下文）
读记忆：画像+概念列表；不写
▼
