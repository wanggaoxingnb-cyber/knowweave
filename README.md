# 织识 KnowWeave

> 记得你学过什么的 AI 学习助手 —— 喂任意资料，生成图文/播客讲解，把新知识和旧知识织成一张越织越大的网。

## 这是什么
- 个人 AI 学习工作台，面向想学 AI 的人（产品经理 / 职场人）
- 输入：论文 / 推文 / 公众号文章 / Markdown / 截图 / 直接提问
- 输出：图文概念卡 / 播客音频 / 知识图谱 / 串联回答
- 记忆：Markdown 概念文件夹 + 用户画像，AI 自动读写，掌握度随时间生长
- 画像：记住你的身份、爱好与熟悉领域（产品经理、英雄联盟…），用你熟悉的东西举例
- 差异化：不止生成讲解，更记得你学过什么，新旧概念自动串联
